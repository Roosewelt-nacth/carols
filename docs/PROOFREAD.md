# Proofreading the Tamil carols

The Tamil text was typed from a blurry scan of the booklet. Please compare each song with its original page
(open `public/Carols.pdf`, or the Original page button in the app) and fix `src/data/songs.ta.ts`.
When a song is correct, change `check: true` to `check: false` for that song.
